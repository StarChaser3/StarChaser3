### What I'm building here

**[agent-verified-qa](https://github.com/StarChaser3/agent-verified-qa)** — a multi-agent test runner that reports a finding *only* after independent "refuter" agents have tried and failed to disprove it. The goal is to kill the false positives that AI test agents tend to produce. *(Work in progress: the verification logic and its tests are done; the agent/target integration is next.)*

**[uds-ecu-sim](https://github.com/StarChaser3/uds-ecu-sim)** — a simulated automotive ECU that answers UDS (ISO 14229) diagnostics over virtual CAN, with a test suite built around the negative-response paths (wrong key, bad session, retry lockout) — the places real diagnostic bugs actually live. Runs with no hardware.
